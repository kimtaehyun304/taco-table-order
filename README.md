# 테이블 오더
* [백엔드] php 8.3, laravel 13.8, Eloquent ORM, composer, sqlLite
* [프론트] blade, tailwind 4, vite

# 기능
* 음식 메뉴 조회 (파스타, 피자, 음료)
* 장바구니
* 주문

# 실행 방법
1. npm install
2. php artisan migrate:fresh
3. php artisan db:seed
4. composer run dev
5. localhost:8000/foods 접속

# 프로젝트 생성 과정
* [라라벨 공식 문서 보고 설치](https://laravel.com/docs/13.x#installing-php)
